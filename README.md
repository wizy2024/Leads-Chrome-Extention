this is a chrome extention software that is used to extend the abilities of the chrome browser 
In this case it helps people save the url of the current open page in there browser to the local storage 

How to use 
1.go to setting and locate Chrome extention manager
2.open the manager and then upload or load  the relevent code files of the extention and then save it 
3.after that go to chrome browser and open the puzzle icon that represents extentions on the top
4.open the leads tracker and use it from there
